1. What is the data used for?

The app uses photos you select or take at your command to provide an approximate measurement of the item. The calculation is performed on the device. The developer does not receive photos, dimensions, weight or other entered values ​​through the application.

2. Photos and camera

Shooting opens only after clicking “Take photo” through the installed camera application. Selecting a file opens a system window; the app does not request access to the entire gallery. The image and its orientation are used. The app does not use GPS coordinates from the metadata to determine location.

3. On-device storage

Reduced working copies of snapshots are stored in a private application cache. They can be saved after closing the screen until a new measurement session, clearing temporary photos or clearing the cache by the system. Incomplete camera shots may also remain in the cache until cleared. The last entered sizes and settings are saved in the application's private storage. Automatic backup of this data is disabled in the application settings.

4. Data transfer

The application has no advertising, analytics, server processing and INTERNET permission. The built-in AndroidX, Kotlin and Guava libraries are used to run the application, not for advertising or analytics. The application does not send user data to the developer and does not sell it.

When saving a PDF, you choose the location through the Android system window. If a cloud drive is selected, the file is processed by that storage provider according to its rules. The PDF contains the diagram and dimensions of the box, not the original photos. The system camera, file provider, Google Play and other separately installed services may have their own data processing rules.

5. Removal

The "Delete Temporary Photos" button on this screen only deletes the app's work photos. The originals from the gallery and the PDFs you saved remain in place. Settings and dimensions can be deleted through the “Clear data” system action for the application or by deleting the application itself. Photos, PDFs and copies saved outside the application are deleted separately in the selected storage.

6. Accounts and requests

There is no registration or user accounts in the application. To work, you do not need to provide your name, phone number or email. If you independently contact support using the publisher's contact, the content of the request is processed by the publisher for a response according to its support rules.

7. Changes

If server features, advertising, analytics or data handling change, this privacy policy and the Google Play disclosures must be updated before the new version is distributed.
